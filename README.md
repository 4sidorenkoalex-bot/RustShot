# RustShot

RustShot — утилита для снимков экрана в духе ShareX. Сохраняет PNG и копирует снимки в буфер обмена.

## Как запустить

1. Скачайте `RustShot.exe` из [GitHub Releases](https://github.com/4sidorenkoalex-bot/RustShot/releases) (готовая локальная сборка находится в `dist\RustShot.exe`).
2. Запустите файл двойным щелчком. Нужна **Windows 10 или 11 x64**. Rust, Node.js, установщик и права администратора не нужны. Для 32-битной Windows, macOS и Linux сборок нет. Отдельной сборки для Windows ARM64 нет.
3. При обновлении сначала закройте старую версию через значок RustShot в трее → **Выход**, чтобы освободить горячие клавиши.

## Снимки экрана

| Действие | Горячая клавиша |
| --- | --- |
| Выделить область мышью | `Ctrl + Print Screen` |
| Снять весь рабочий стол, включая другие мониторы | `Print Screen` |
| Снять видимую область активного окна | `Alt + Print Screen` |

- Чтобы отменить выбор области, нажмите `Esc` или правую кнопку мыши.
- Если сочетание занято ShareX или другим приложением для скриншотов, закройте это приложение и перезапустите RustShot. Если `Print Screen` открывает «Ножницы», проверьте настройку Windows «Специальные возможности → Клавиатура», которая назначает `Print Screen` на захват экрана.
- Кнопка «Активное окно» в интерфейсе даёт 3 секунды, чтобы переключиться на нужное окно. Горячая клавиша снимает без этой задержки.
- По умолчанию RustShot сохраняет PNG в системную папку `Изображения\RustShot`. Чтобы изменить её, откройте **Настройки → Папка сохранения → Выбрать папку…**. Выбор запоминается после перезапуска; кнопка **По умолчанию** возвращает исходную папку.
- Кнопка **Открыть папку** открывает текущую папку сохранения. История показывает до шести последних снимков из неё и загружает предпросмотр в фоне. При смене папки прежние файлы не перемещаются и не удаляются.
- По умолчанию крестик сворачивает RustShot в трей, где горячие клавиши продолжают работать. В разделе **Настройки** можно выбрать «Свернуть в трей» или «Закрыть программу»; выбор сохраняется после перезапуска. Дважды щёлкните по значку, чтобы открыть окно, или выберите «Выход» в его контекстном меню для полного закрытия.
- RustShot не отправляет снимки в сеть. Если Windows синхронизирует папку «Изображения» или буфер обмена, изображения могут синхронизироваться средствами самой Windows.

PNG сохраняется в исходном разрешении без масштабирования и потерь при сжатии. Как и при обычном PNG-захвате в ShareX, файл сохраняет полученные пиксели; попиксельное совпадение не гарантируется, например при HDR. Защищённое содержимое может отображаться чёрным. Запись видео, редактор и загрузка на хостинги не реализованы.

## Сборка из исходников

Этот раздел нужен только тем, кто собирает программу сам. Понадобятся [Rust через rustup](https://rustup.rs/) и Windows-линкер. Для стандартного Rust MSVC установите [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с набором **Разработка классических приложений на C++**, включающим MSVC и Windows SDK. Откройте PowerShell в папке с `Cargo.toml`:

```powershell
cargo test --locked
cargo build --locked --release
.\target\release\rustshot.exe
```

Если MinGW не может открыть файлы из пути с кириллицей, перед сборкой задайте каталог без кириллицы, например `$env:CARGO_TARGET_DIR = "$env:LOCALAPPDATA\Temp\rustshot-target"`. Готовый файл будет в `release` внутри этого каталога.
